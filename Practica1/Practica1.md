##¿Cuáles son las principales diferencias entre Haskell y Rust?##
"Brevemente, su orientacion es mas que nada su principal diferencia, ya que Haskell busca la maxima expresividad matematica y abstraccion, mientras que Rust es mas orientado al desarrollo de sistemas, busca el aprovechar cada mb de ram disponible "
##¿Por qué Haskell no ha alcanzado una adopción significativa en la industria del software?
"Por que funciones como llamar a una base de datos, requiere un alto nivel de abstraccion y seria mucho mas complejo el llevarlas a la practica que co otros lenguajes ya existentes"
##Si tuvieras que explicarle a una persona que no es de CC la función que cumple Git frente a la de GitHub, ¿cómo se lo explicarías?##
"Basicamente, recurrir al recurso de la analogia, tenemos a Git sea como la camra y galeria de tu telefono, puedes tomar fotos, editarlas y moverlas como tu quieras, y en git puedes guardar para ti versiones de tu codigo y asi de forma local, y GitHub es un instagram, para publicar tus codigos de forma privada o publica y tener tu propio perfil "
